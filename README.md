## Node Version
10.15.2

### `npm start`
It will start the application into development environment 
Please update the respective value of `.env.development` before start

### `npm run build`
It will create the production build.
Please update the respective value of `.env` before build.

### CHANGE THEME COLOR 
Open `src->scss->utils->_variable.scss` file
Change the value of `$color-1st`. It will change the whole web app color

### CHANGE THE FAVICON
Open `public` folder from root
Change or replace the `favicon.ico` 

### CHANGE THE LOGO
Open `public` folder from root
Change or replace the `logo.png`
